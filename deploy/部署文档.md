# RenovationOps 部署说明

`deploy/` 只提供可公开的部署示例，不包含真实服务器地址、凭据或产物。

## 构建

确保 `java`、`mvn`、`node` 和 `npm` 已加入 `PATH`，然后运行 `deploy/build.bat`。构建脚本会生成：

- `deploy/ruoyi-admin.jar`
- `deploy/dist/`

这些产物已被 Git 忽略。

## 后端配置

运行前设置环境变量，完整列表见项目根目录 `.env.example`。至少必须设置高强度随机 `JWT_SECRET`；生产数据库和 Druid 控制台也必须使用独立强密码。

## Nginx

复制并调整 `deploy/nginx.conf` 中的监听域名、静态文件路径和后端地址。示例地址不代表真实基础设施。

## FRP（可选）

1. 将 `frp/frpc.example.toml` 复制为 `frp/frpc.toml`。
2. 将 `frp/frps.example.toml` 复制为 `frp/frps.toml`。
3. 替换 `203.0.113.10`、`CHANGE_ME`、端口和代理名称。
4. 不要提交生成的 `frpc.toml`、`frps.toml` 或 FRP 二进制文件。

`203.0.113.10` 属于文档示例网段，不是可用服务器地址。
